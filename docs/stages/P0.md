**`golden/dump_hf.py` — 实现要点**
1. `torch.manual_seed(seed)` 固定随机性后，`AutoModelForCausalLM.from_pretrained(..., dtype=bf16|fp32, attn_implementation="sdpa")` 加载并 `.eval()`。
2. 输入构造：`np.random.default_rng(seed).integers(100, vocab_size-400, size=seq_len)` 生成 token id 序列（避开词表尾部 special token 区），转 `torch.long` 张量。
3. 核心是一句话：`torch.no_grad()` 下 `model(input_ids, output_hidden_states=True)` **单次前向**，返回对象的 `.hidden_states` 就是 29 元素 tuple（embedding 输出 + 28 层输出）——不注册 forward hook，靠 HF 内建参数拿全中间量。
4. 逐层落盘：`np.save(f"hidden_{i:02d}.npy", h.float().cpu().numpy())`，`.float()` 统一转 fp32、`.cpu()` 拉回主机；logits 同理。
5. greedy 续写走 `model.generate(do_sample=False, max_new_tokens=N)`，存 `greedy_ids.npy`（输出级 golden）。
6. `meta.json` 写入 `config.to_dict()` + torch/transformers 版本 + seed + 完整输入 ids——保证任意时刻确定性复现。

**`golden/check_diff.py` — 实现要点**
1. 先读两份 `meta.json` 校验 `input_ids` 一致（输入不同则对比无意义，直接退出）。
2. 以 A 侧 `sorted(glob("*.npy"))` 枚举文件，三类分支处理：`greedy_ids.npy` 要求**逐元素完全相等**并报告首个差异下标；shape 不一致直接 FAIL；数值张量转 **float64** 后做差（避免 fp32 求差自身引入误差）。
3. 误差三元组：max abs diff（判定依据）、mean abs diff（整体漂移）、max rel diff（分母 `max(|b|, 1e-6)` 防除零；近零元素处该列虚高，仅供观察）。
4. 汇总最差张量 vs `--tol`，`SystemExit` 退出码 0/1，可被脚本链直接调用。

**`bench/dataset.py` — 实现要点**
1. `SPEC` 字典声明四类负载（条数/prompt_len/output_len），`shared_prefix_len=32768` 为常量。
2. 单个 `np.random.default_rng(seed)` 顺序生成：先一次性生成 32K 共享前缀列表，shared_prefix 类每条 = 共享前缀 + 独立段（`integers` 补齐差值），其余类独立生成——同 seed 必然得到逐字节相同的 ids。
3. id 取值域 `[100, vocab-400)`：避开 Qwen2 的 special tokens（≥151643）。
4. 输出单个 JSON：spec 元信息 + requests 数组（`prompt_ids` 内联存储，21 条约几 MB）。

**`bench/run_local.py` — 实现要点**
1. `BACKENDS = {"hf": build_hf, ...}` 注册表模式：backend 名 → 模型构造函数。P1 起自研引擎加一个键值即可复用同一套计时代码。
2. **计时核心 `run_one()`，手写两段式循环而不用 `generate()`**（generate 是黑盒，测不出 prefill/decode 分界）：
   - *prefill*：整个 prompt 一次 `model(input_ids, use_cache=True)`，`torch.cuda.synchronize()` 后 `perf_counter` 差值 → TTFT（CUDA 异步，必须同步才能取到真实耗时）；
   - *decode*：`logits[0, -1].argmax()` 取 greedy 首 token，循环 N−1 步，每步把**单 token**（`.view(1,1)`）连同 `past_key_values` 喂回 forward——KV cache 由 transformers 的 DynamicCache 在步间传递，每步只算 1 个 query 对全历史的 attention，这正是 decode 步耗时远小于 prefill 的原因；
   - 每步 `synchronize + perf_counter` 记入 `decode_ms` 列表。
3. 汇总：`np.percentile` 取 p50/p99，吞吐 = 总输出 token ÷ 总耗时；`torch.cuda.max_memory_allocated()` 记显存峰值。
4. 预热：取第一条截断 64 token 跑几步（消除 kernel 加载/CUDA context 首帧开销），结果 JSON 附带完整 env 元信息。

**`bench/compare.py` — 实现要点**
1. **模块顶部、`import matplotlib` 之前**执行 `os.environ.setdefault("MPLCONFIGDIR", ~/.cache/mpl)` 并 makedirs——环境变量必须在库 import 前生效，这解决了 `~/.config` 只读导致 matplotlib 崩溃的问题。
2. 读 results JSON 抽取 `summary` 字段拼表打印；`--plot` 时用 Agg 后端（无显示环境）画两条水平条形图（TPOT p50 / tok/s）落 PNG。

## 踩坑记录

1. **WSL2 GPU 透传失效**：`nvidia-smi` 报 `GPU access blocked by the operating system`（Windows 侧正常、`/usr/lib/wsl/lib/libcuda.so` 注入文件还在）。同日 WSL NAT 网络也断（连 baidu 都超时）——两者同源，`wsl --shutdown` 重启 WSL 会话解决。
2. **1.5B 权重不完整**：`models/Qwen2.5-1.5B-Instruct/` 最初只有 config+tokenizer（11MB），缺 2.9GB safetensors；已补全。
3. **transformers 5.x**：`AutoModelForCausalLM` 必须显式 `from transformers import`（不再从包根暴露）；`from_pretrained(dtype=...)` 取代 `torch_dtype`。
4. **`~/.config` 只读**（WSL 挂载怪癖）：matplotlib 缓存目录不可写。`bench/compare.py` 内 `MPLCONFIGDIR` 兜底到 `~/.cache/mpl`，无需改系统。
5. numpy 标量列表直接 `torch.tensor()` 极慢，先 `np.asarray`。
6. check_diff 的 rel diff 列在近零元素处会虚高（分母 clamp 1e-6），跨精度对比时忽略该列，以 max/mean abs diff 为准。
