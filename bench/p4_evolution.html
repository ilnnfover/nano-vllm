详细数据

P2 · KV cache 引入的效果

nano-eager（无 cache，每步重算）：TPOT p50=35.34ms p99=49.96ms · 吞吐 25.05 tok/s
nano-cache（KV cache 复用）：TPOT p50=21.57ms p99=23.35ms · 吞吐 45.64 tok/s
→ TPOT p50 降低 1.64×，p99 降低 2.14×，吞吐提升 1.82×
（warmup=1, repeat=3 中位数，方差 <3%；旧版单次无 warmup 高估了加速比）

P3 · PagedAttention + 自研 Triton kernel

KV waste rate：P2 连续预分配 15% → P3 分页 1.44%（1025 token）/ 0.024%（32768 token）
Triton vs torch（预热后）：seq=128→1.29×, 512→1.25×, 1024→1.12×, 4096→1.51×, 8192→1.26×
32K 长上下文：prefill 3281.7ms · peak 6.59GB · decode 77.8ms · waste 0.024%
block_size 扫描：bs=8→28.2ms, bs=16→27.0ms, bs=32→28.9ms, bs=64→25.9ms（TPOT p50）

P4 · 连续批处理 + varlen prefill 拼批

吞吐（12 请求 128/1024/8192 混排，warmup=1 repeat=3 中位数）：
  torch 后端：P4 47.57 vs P3 16.72 tok/s = 2.85× ✅
  flashinfer 后端：P4 69.19 vs P3 23.71 tok/s = 2.92× ✅（反超 torch）
TPOT p99（纯 decode step 间隔）：
  torch：chunked 103.51ms / non-chunked 103.56ms = 0.999×（不劣化）
  flashinfer：chunked 101.51ms / non-chunked 123.43ms = 0.822×（chunked 略优）
关键洞察：varlen 拼批收益主来自 MLP+QKV proj 一次算完（12 次 forward → 1 次），而非 attention kernel 本身
